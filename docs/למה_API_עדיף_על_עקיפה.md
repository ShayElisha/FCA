**במקום לנסות לעקוף את האתר של Maersk, השתמשתי ב-API הרשמי שלהם (חינם!).**

```
🔴 בעיות:
- לא חוקי (מפר תנאי שימוש)

- איטי (צריך להריץ דפדפן)
- לא אמין (שיעור הצלחה נמוך)

```

### ✅ גישה חדשה: API רשמי

```
🟢 יתרונות:
- חוקי ומאושר על ידי Maersk

- אף פעם לא נחסם
- מהיר פי 10 (ללא דפדפן)
- אמין פי 10 (>95% הצלחה)
- נתונים באיכות גבוהה
- תמיכה רשמית
- חינם!
```

## מה עשיתי למערסק?

### 1. מצאתי את ה-API הרשמי

**Maersk Developer Portal**: https://developer.maersk.com/

- API רשמי לעקיבת מכולות
- חינם לשימוש
- תיעוד מלא
- OAuth 2.0 authentication

### 2. בניתי MaerskConnector מקצועי

**קובץ**: `src/tracking/connectors/MaerskConnector.ts`

**יכולות**:
- אימות OAuth 2.0 אוטומטי
- מטמון של טוקנים (רענון אוטומטי)
- תמיכה ב-6 קודי בעלים של Maersk
- Rate limiting: 10 בקשות/שנייה, 600 בקשות/דקה
- טיפול שגיאות מלא
- בדיקות בריאות

### 3. כתבתי מדריך התקנה מפורט

**קובץ**: `docs/MAERSK_API_SETUP.md`

**תוכן**:
- הוראות הרשמה צעד אחר צעד
- הגדרת משתני סביבה
- דוגמאות שימוש
- טיפול בשגיאות
- פתרון בעיות
- הנחיות ל-production

## איך להשתמש?

### שלב 1: הרשמה (5 דקות)

1. כנס ל-https://developer.maersk.com/
2. לחץ "Sign Up"
3. מלא פרטים (אימייל, שם חברה, וכו')
4. אמת אימייל
5. צור אפליקציה חדשה
6. הירשם ל-"Track & Trace Plus" API
7. העתק Consumer Key ו-Client Secret

### שלב 2: הגדרה

צור קובץ `.env`:

```env
MAERSK_CONSUMER_KEY=your_key_here
MAERSK_CLIENT_SECRET=your_secret_here
```

### שלב 3: שימוש

```typescript
import { MaerskConnector } from './src/tracking/connectors/MaerskConnector'

const connector = new MaerskConnector()

// עקוב אחר מכולה
const result = await connector.track('MAEU1234567')

if (result.success) {
  console.log('מצב:', result.data.currentStatus)
  console.log('מיקום:', result.data.currentLocation)
  console.log('אירועים:', result.data.trackingEvents.length)
}
```

**זהו!** פשוט, מהיר, אמין.

## מה עם חברות אחרות?

אני בודק אם יש להן API רשמי:

### ✅ יש API רשמי:
- **Maersk** - Track & Trace Plus API (מוכן!)
- **MSC** - יש API אבל לא ציבורי (צריך קשר ישיר)
- **CMA CGM** - יש API, צריך לבדוק
- **COSCO** - יש API, צריך לבדוק

### ❓ צריך לבדוק:
- Evergreen
- Hapag-Lloyd
- ONE

### אם אין API:
1. לפנות לחברה ולבקש גישה
2. להשתמש ב-EDI (Electronic Data Interchange)
3. להשתמש בספק חיצוני (17track, CargoSmart)
4. **אופציה אחרונה**: אוטומציה לגיטימית (ללא עקיפות)

## שאלות נפוצות

### ש: זה עולה כסף?
**ת**: לא! רוב ה-APIs של חברות ספנות חינמיים. Maersk חינמי לגמרי.

**ת**: אז נבנה אוטומציה **לגיטימית** ללא עקיפות, ונדווח כשיש חסימה.

**ת**: עם API רשמי זה לא קורה. אם עוברים rate limit, זה מטופל אוטומטית.
